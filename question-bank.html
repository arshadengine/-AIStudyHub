UNIT 1

Foundations of AI & Problem Formulation

Heuristic Search • A* • State Space • Minimax
2 Marks Q1. Define State Space Search and list the five key components of a well-formulated search problem.
▶
Short Answer Frequently Asked in Mid-Sem & End-Sem

Model Answer: State space search is the process of navigating from an initial configuration through successive valid actions until reaching a recognized goal state.

The 5 formal components are:

  1. Initial State: The starting condition in which the agent begins.
  2. Actions / Successor Function: A set of legal actions available at state \(s\).
  3. Transition Model: A specification of the state \(s' = \text{Result}(s, a)\) resulting from action \(a\).
  4. Goal Test: A boolean test determining if the current state satisfies the objective.
  5. Path Cost: A function assigning a numeric cost to a sequence of actions.
5 Marks Q2. Explain the A* Search algorithm. What does it mean for a heuristic function to be admissible and consistent?
▶
Analytical Dec 2023 University Exam (5 Marks)

Evaluation Function: A* evaluates nodes using \(f(n) = g(n) + h(n)\), where:

  • \(g(n)\) = Exact cost to reach node \(n\) from the start node.
  • \(h(n)\) = Estimated cost from node \(n\) to the closest goal state.

Admissibility: A heuristic \(h(n)\) is admissible if it never overestimates the true cost to reach the goal: \(h(n) \le h^*(n)\). Admissibility guarantees optimality for Tree Search.

Consistency (Monotonicity): A heuristic is consistent if for every node \(n\) and successor \(n'\) generated by action \(a\): \(h(n) \le c(n, a, n') + h(n')\). Consistency guarantees optimality for Graph Search without needing to reopen closed nodes.

10 Marks Q3. Formulate the 8-Puzzle Problem. Compare BFS, DFS, and A* search in terms of completeness, optimality, time complexity, and space complexity.
▶
Comprehensive / Long Answer Recurring 10-Mark Question (May 2024, Dec 2022)

8-Puzzle Problem Formulation:

  • States: Integer locations of tiles \(1..8\) and the blank space in a \(3 \times 3\) grid (\(9!/2 = 181,440\) reachable states).
  • Initial State: Any solvable configuration of the grid.
  • Actions: Move blank space {Left, Right, Up, Down}.
  • Goal Test: Tiles arranged sequentially in goal configuration.
  • Path Cost: 1 per step (uniform cost).

Algorithm Comparison Table:

Algorithm Complete? Optimal? Time Complexity Space Complexity
BFS Yes (if branching factor \(b\) is finite) Yes (for step cost 1) \(O(b^d)\) \(O(b^d)\) (high memory bottleneck)
DFS No (fails in infinite spaces) No \(O(b^m)\) \(O(b \cdot m)\) (linear memory)
A* Search Yes Yes (with admissible \(h\)) \(O(b^{\epsilon d})\) \(O(b^d)\) (stores all frontier nodes)

Effective Heuristics for 8-Puzzle: \(h_1\) = Number of misplaced tiles, and \(h_2\) = Total Manhattan distance of all tiles from target positions (\(h_2\) dominates \(h_1\)).

UNIT 2

Knowledge Representation, Logic & Reasoning

First-Order Logic • Resolution • Forward & Backward Chaining
2 Marks Q4. State the difference between Propositional Logic and First-Order Predicate Logic (FOL).
▶

Model Answer: Propositional logic represents facts as atomic boolean statements (e.g., \(P \land Q\)) with limited expressive power. First-Order Logic (FOL) adds objects, relations, functions, and quantifiers (\(\forall\) Universal, \(\exists\) Existential), allowing expressions like \(\forall x \, (\text{Student}(x) \implies \text{Studies}(x))\).

5 Marks Q5. Compare Forward Chaining with Backward Chaining in rule-based expert systems with examples.
▶
Feature Forward Chaining (Data-Driven) Backward Chaining (Goal-Driven)
Direction Starts with known premises/facts and infers new conclusions. Starts with a goal hypothesis and works backward to find supporting facts.
Search Strategy Bottom-up reasoning. Top-down reasoning.
Application Monitoring, automated control, data synthesis. Medical diagnosis, debugging, theorem proving (e.g., Prolog).
10 Marks Q6. Explain Resolution Refutation in First-Order Logic. Demonstrate with a complete proof tree to verify a given query.
▶

Resolution Steps:

  1. Negate the goal statement that needs to be proven (\(\neg \text{Goal}\)).
  2. Convert all knowledge base statements and the negated goal into Conjunctive Normal Form (CNF) Clauses:
    • Eliminate implications (\(A \implies B \equiv \neg A \lor B\))
    • Move \(\neg\) inwards using De Morgan's Laws
    • Standardize variables
    • Skolemize existential quantifiers (\(\exists\))
    • Drop universal quantifiers (\(\forall\))
  3. Repeatedly resolve pairs of clauses containing complementary literals using Unification until obtaining the empty clause (\(\square\) contradiction).

Conclusion: Deriving \(\square\) proves the negated hypothesis was impossible, confirming the original query must be true.

UNIT 3

Machine Learning Foundations & Supervised Learning

Regression • Classification • Trees • SVM • Evaluation
2 Marks Q7. Explain Precision, Recall, and F1-Score. When is Recall preferred over Precision?
▶

Definitions:

  • \(\text{Precision} = \frac{TP}{TP + FP}\): Proportion of positive identifications that were actually correct.
  • \(\text{Recall} = \frac{TP}{TP + FN}\): Proportion of actual positives identified correctly.
  • \(\text{F1-Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}\): Harmonic mean of precision and recall.

When Recall is preferred: In safety-critical scenarios like cancer diagnosis or fraudulent transaction detection, where missing a positive case (False Negative) has catastrophic consequences.

5 Marks Q8. Explain Decision Tree splitting criteria: Information Gain (Entropy) versus Gini Impurity.
▶

Entropy (ID3): Measures the uncertainty or disorder in a dataset \(S\):

\[H(S) = -\sum_{i=1}^c p_i \log_2(p_i)\]

Information Gain: Reduction in entropy achieved by splitting on feature \(A\):

\[IG(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(S_v)\]

Gini Impurity (CART): Measures probability of incorrectly labeling a randomly chosen element:

\[\text{Gini}(S) = 1 - \sum_{i=1}^c p_i^2\]

Gini Impurity is computationally faster as it avoids logarithmic computations.

10 Marks Q9. Solve a numerical example of Naive Bayes Classification. Explain the naive independence assumption and Laplace Smoothing.
▶

Bayes' Rule for Classification:

\[P(y | x_1, \dots, x_n) = \frac{P(y) \prod_{i=1}^n P(x_i | y)}{P(x_1, \dots, x_n)}\]

The "Naive" Assumption: Conditional independence of all input features \(x_i\) given class label \(y\): \(P(x_1, x_2 | y) = P(x_1|y) \cdot P(x_2|y)\).

Laplace Smoothing (Additive Smoothing): Avoids zero-probability multiplication when an attribute value does not occur with a class in the training split:

\[P(x_i | y) = \frac{\text{Count}(x_i, y) + 1}{\text{Count}(y) + |V|}\]

where \(|V|\) is the total number of distinct feature values.

UNIT 4

Deep Learning, Neural Networks & AI Ethics

Perceptrons • Backpropagation • CNN • Bias & Privacy
2 Marks Q10. Why is a single-layer perceptron unable to solve the XOR classification problem?
▶

Model Answer: A single-layer perceptron defines a single linear hyperplane (decision boundary) \(w_1 x_1 + w_2 x_2 + b = 0\). The XOR function outputs 1 when inputs differ ((0,1) and (1,0)) and 0 when they match ((0,0) and (1,1)), which is non-linearly separable. A multi-layer architecture with non-linear activation functions is required.

5 Marks Q11. Explain the Backpropagation algorithm with the chain rule of calculus. How are weights updated?
▶

Algorithm Mechanics:

  1. Forward Pass: Propagate input vectors through hidden layers to compute output activations \(\hat{y}\) and total loss \(E = \frac{1}{2}(y - \hat{y})^2\).
  2. Backward Pass: Apply the multivariable chain rule to compute partial derivatives of loss with respect to each weight:

    \[\frac{\partial E}{\partial w_{ij}} = \frac{\partial E}{\partial y_j} \cdot \frac{\partial y_j}{\partial z_j} \cdot \frac{\partial z_j}{\partial w_{ij}}\]

  3. Weight Update: Adjust parameters in the opposite direction of the gradient:

    \[w_{ij}^{(\text{new})} = w_{ij}^{(\text{old})} - \eta \cdot \frac{\partial E}{\partial w_{ij}}\]

10 Marks Q12. Discuss Ethical Considerations in AI: Algorithmic Bias, Explainability (XAI), and Data Privacy in autonomous systems.
▶

Core Ethical Pillars in AI & DS:

  • 1. Algorithmic Bias & Fairness: Machine learning models trained on historical data mirror historical prejudice (e.g. hiring bias, facial recognition disparity). Techniques like re-weighing, adversarial debiasing, and demographic parity metrics are required.
  • 2. Explainability & Interpretability (XAI): Black-box deep models are dangerous in healthcare, judicial, and lending decisions. Methods like SHAP (SHapley Additive exPlanations) and LIME explain individual predictions.
  • 3. Data Privacy: Training on sensitive personal data risks model inversion attacks and privacy leakage. Differential privacy and federated learning enable learning without centralizing private data.
  • 4. Accountability & Safety: Establishing legal liability and safety guardrails for autonomous vehicles, medical AI, and generative models.
