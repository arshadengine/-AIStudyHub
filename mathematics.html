Unit 1

Linear Algebra for Machine Learning

Essential for Dimensionality Reduction & Deep Learning

Linear algebra provides the mathematical vocabulary to represent data, weights, and high-dimensional spaces in artificial intelligence.

  • Vectors, Vector Spaces & Norms (L1, L2, Frobenius)
  • Matrix Operations, Determinants & Inverse Matrices
  • Dot Products, Projections & Orthogonality
  • Eigenvalues and Eigenvectors (Av = λv)
  • Singular Value Decomposition (SVD)
  • Principal Component Analysis (PCA) Derivation
Why it matters in AI: Every dataset is a matrix \(X \in \mathbb{R}^{n \times d}\), where rows are observations and columns are features. Weights in deep neural networks are weight tensors updated via matrix multiplication.
Unit 2

Multivariate Calculus & Optimization

Engine of Model Training & Backpropagation

Machine learning is fundamentally an optimization problem: finding model parameters that minimize an objective loss function.

  • Limits, Continuity & Differentiation Rules
  • Partial Derivatives & Gradients (\(\nabla f\))
  • Multivariate Chain Rule (Foundation of Backprop)
  • Jacobian Matrix and Hessian Matrix (Curvature)
  • Convex Optimization & Saddle Points
  • Stochastic Gradient Descent (SGD), Momentum & Adam Optimizer
Unit 3

Probability & Inferential Statistics

Handling Uncertainty & Data Distributions

Data Science and Machine Learning models make probabilistic inferences under noise and uncertainty.

  • Axioms of Probability & Conditional Probability
  • Bayes' Theorem: \(P(A|B) = \frac{P(B|A)P(A)}{P(B)}\)
  • Random Variables, Expectation, Variance & Covariance
  • Distributions: Gaussian (Normal), Bernoulli, Binomial, Poisson
  • Maximum Likelihood Estimation (MLE) & MAP
  • Central Limit Theorem, Hypothesis Testing & p-values
Interactive Code

Mathematical Concepts in Python (NumPy)

Here is how linear algebra and gradient calculations translate directly into Python code:

import numpy as np

# 1. Matrix Multiplication & Vector Dot Product
A = np.array([[2, 1], [1, 3]])
v = np.array([1, 2])
result = np.dot(A, v)
print("A * v =", result)

# 2. Eigenvalues and Eigenvectors (used in PCA)
eigenvalues, eigenvectors = np.linalg.eig(A)
print("Eigenvalues:", eigenvalues)
print("Eigenvectors:\n", eigenvectors)

# 3. Simple Gradient Step for Mean Squared Error Loss
# Loss = (y_pred - y_true)^2
y_true = 5.0
weight = 2.0
x = 2.0  # input feature
learning_rate = 0.05

for step in range(5):
    y_pred = weight * x
    loss = (y_pred - y_true)**2
    # Gradient: dLoss/dWeight = 2 * (y_pred - y_true) * x
    grad = 2 * (y_pred - y_true) * x
    weight -= learning_rate * grad
    print(f"Step {step+1}: Weight = {weight:.4f}, Loss = {loss:.4f}")
