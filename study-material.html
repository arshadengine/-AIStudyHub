Subject 01

Artificial Intelligence (AI)

Open Full AI Guide → Unit 1 & 2 Questions

This subject covers fundamental concepts of rational decision-making, automated reasoning, heuristic search algorithms, and modern autonomous agent architectures.

Unit 1: Search & Problem Solving

  • State Space Representation & Problem Formulation
  • Uninformed Search: BFS, DFS, Uniform Cost Search
  • Informed (Heuristic) Search: A*, Greedy Best-First
  • Adversarial Search: Minimax, Alpha-Beta Pruning

Unit 2: Logic, Knowledge & Reasoning

  • Propositional Logic & First-Order Predicate Logic (FOL)
  • Inference Rules, Forward & Backward Chaining
  • Resolution Theorem Proving & Unification
  • Ontologies, Semantic Networks & Conceptual Graphs
Reference Text: Artificial Intelligence: A Modern Approach by Stuart Russell & Peter Norvig (Pearson).
Subject 02

Machine Learning (ML)

Open ML Notes → Read ML Roadmap

Explores algorithms that iteratively learn patterns from observational data, construct predictive models, and optimize performance over unseen test instances.

Unit 3: Supervised Learning

  • Linear Regression: Cost function, Normal Equation, SGD
  • Logistic Regression: Sigmoid, Log-loss, Decision Boundary
  • Decision Trees (ID3, CART), Information Gain, Gini Impurity
  • Support Vector Machines (SVM), Maximum Margin, Kernels
  • Ensemble Methods: Random Forest, AdaBoost, XGBoost

Unit 4: Unsupervised Learning & Validation

  • Clustering: K-Means, Elbow Method, Hierarchical Clustering
  • Dimensionality Reduction: Principal Component Analysis (PCA)
  • Validation: K-Fold Cross Validation, Bias-Variance Tradeoff
  • Metrics: Confusion Matrix, Precision, Recall, F1, ROC-AUC
Reference Text: Pattern Recognition and Machine Learning by Christopher M. Bishop | Hands-On Machine Learning by Aurélien Géron.
Subject 03

Data Science (DS)

Open Data Science Notes →

Covers the end-to-end data lifecycle: data acquisition, wrangling, exploratory data analysis, statistical tests, storytelling, and actionable insights.

Exploratory Data Analysis (EDA)

  • Data Imputation: Mean, Median, Mode, KNN imputer
  • Outlier Detection: IQR method, Z-Score, Box plots
  • Categorical Encoding: One-Hot, Ordinal, Target Encoding
  • Feature Scaling: StandardScaler, MinMaxScaler, RobustScaler

Data Visualization & Reporting

  • Matplotlib & Seaborn: Heatmaps, Pairplots, Histograms
  • Interactive Dashboards: Plotly, Streamlit web apps
  • Correlation Analysis: Pearson vs Spearman rank coefficient
  • Communicating statistical findings to stakeholders
Reference Text: Python for Data Analysis by Wes McKinney (O'Reilly).

Mathematics for AI & DS
